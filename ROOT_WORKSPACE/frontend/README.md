# Frontend

Production UI is the TanStack Start app in `atlas-forge-console` (not a separate Next.js app).

- Repo: cantgetalonggta-png/atlas-forge-console
- Deploy: Vercel project atlas-forge-console
- Local: `npm run dev` (port 8080)

DeerFlow has its own frontend package mirrored under `source-mirror/deer-flow/frontend.package.json`.
