### Agent Framework Orchestration

2. **Publishing Data**: When an agent (e.g., the Web Scraping Agent) completes its task and has data to share, it publishes this data onto a specific topic (e.g., `scraped_data`). The message broker handles the routing.

API authentication is a critical aspect of securely accessing web services and ensuring that only authorized users or applications can interact with an API. The process generally involves various mechanisms depending on the type of API and intended use. Below, I've outlined the common methods of API authentication, how they work, and steps to ensure billing data is linked.

### API Authentication Methods

1. **API Keys**
   - An API key is a unique identifier used to authenticate a client making requests to an API.
   - **Steps:**
     1. **Registration**: The developer registers an application with the API provider, receiving a unique API key.
     2. **Subsequent Requests**: The API key is included in the request headers or query parameters.
     3. **Verification**: The API server checks the provided API key against its database of valid keys.

2. **OAuth 2.0**
   - OAuth 2.0 is a widely used authorization framework that allows third-party applications to obtain limited access to a service.
   - **Steps:**
     1. **Authorization Request**: The application requests authorization from the user to access their data.
     2. **User Grant**: The user logs in and grants permission, leading to an authorization code being issued to the application.
     3. **Token Exchange**: The application exchanges the authorization code for an access token and a refresh token by making a request to the API provider’s token endpoint.
     4. **API Requests**: The access token is included in the headers of API requests.
     5. **Token Validation**: The API verifies the token with every request to ensure it's still valid.

3. **JWT (JSON Web Token)**
   - JWT is a compact, URL-safe means of representing claims to be transferred between two parties. It is often used in conjunction with OAuth 2.0.
   - **Steps:**
     1. **User Authentication**: The user logs in with credentials (username/password).
     2. **Token Generation**: Upon successful authentication, a JWT is generated with claims about the user and signed using a secret key.
     3. **Token Transmission**: The JWT is sent to the client and is included as a bearer token in the header of subsequent requests.
     4. **Token Validation**: The server verifies the signature and claims of the JWT upon receiving requests to confirm the user’s identity.
